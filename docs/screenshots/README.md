# Screenshots

The README shows three: `keypad.png`, `contacts.png` and `in-call.png`. Each has a
`-dark` copy that the README shows in dark mode.

Take them on a machine with a phone paired, so the device bar, a contact list
and a live call are visible. A capture with no phone shows a warning banner and
a disabled Call button. That is honest, but it is not the program in use.

Around 520 pixels wide is right. The README scales them to 260, so that is a
sharp image on a high-density display without a large file.

Do not photograph a real phone number. The demo phonebook in
`docs/demo-contacts.vcf` uses English names and numbers from the fictional range
+1 212 555 0100 to 0199. The range is unassigned, but dialling one is still a
real call attempt from your SIM.

## Provenance

The screenshots come from version 0.1.0, which was named Foner. For version
0.2.0 the window title text was re-rendered as "Kaller", in the same font and
size. The rest of each image is unchanged. When the interface changes, connect
a phone and retake them.
